# Learnings & Rules

## Project Guidelines
- Keep typography strictly within Fontsource self-hosted variables (Newsreader + Source Sans 3).
- Every interactive element must have min 44x44px target area.
- Focus rings must be visible (`:focus-visible`) and use appropriate tokens (`burgundy` on light, `paper` on dark).
- Avoid `transition-all`. Specify animated properties explicitly (`transition-colors`, `transition-transform`, etc.).
- Never block user flow or scream "DEMO" with giant red warning bars. Instead, use an understated Apple-style glass indicator that feels like part of a professional prototype preview.
- Ensure all telephone, email, WhatsApp, Signal, and external links resolve without dead ends.
